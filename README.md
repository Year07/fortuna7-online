# Fortuna-7 在线双人德州发牌器

这是一个需要部署到公网的 Node.js 小网站。

功能：
- 西奥多创建 6 位房间码，并获得安布罗斯邀请链接。
- 服务器洗牌和保存牌堆；浏览器不会拿到整副牌。
- 西奥多端只收到西奥多底牌；安布罗斯端只收到安布罗斯底牌。
- 两边都会实时看到公共牌。
- 只有西奥多端有“发新的一手 / 发翻牌 / 发转牌 / 发河牌”控制。
- 自动轮换庄家，并显示简单行动顺序提示。
- 当前版本不处理下注和筹码，只负责安全发牌和牌面同步。

## 本地测试
1. 安装 Node.js 18+
2. 在本目录运行：
   npm install
   npm start
3. 浏览器打开 http://localhost:3000

## 部署
这是标准 Node.js + Socket.IO 应用，任何支持长期运行 Node 服务和 WebSocket 的平台都可以部署。
启动命令：npm start
环境变量：无需额外配置
端口：读取平台提供的 PORT
